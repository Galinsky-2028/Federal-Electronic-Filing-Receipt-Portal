## Implemented behavior

`config/engine.lock.json` pins Secure Intake `1.0.0-rc.9` by tag and source commit, verified read-only against the public upstream repository (annotated tag `v1.0.0-rc.9` → `2fb452f23e5e5464db03a3ec95d36c4bc2db4fa4`; `package.json` version `1.0.0-rc.9`). The image digest is unverified and recorded as `null`. `src/engine/contract.mjs` validates the lock, engine liveness/readiness (ADR 0031), the error envelope (ADR 0003) and signed webhook deliveries (ADR 0019). `src/engine/client.mjs` probes a configured engine with bounded, credential-free, redirect-refusing, time-limited requests. `scripts/verify-engine-contract.mjs` (`npm run validate:engine`) runs in `npm run check`.

The portal's HTTP surface is unchanged. `/api/ready` still returns 503 `upstream_unconfigured`; no engine URL, API key or webhook secret is configured or deployed; nothing accepts filings. Contract details and the rc.9 capability assessment are in [ENGINE_CONTRACT.md](../ENGINE_CONTRACT.md).

## Upstream-first review

No upstream behavior is reimplemented. Parsers mirror only the documented upstream response shapes; webhook verification is assigned to consumers by upstream ADR 0019. Missing receipt, signing, time, idempotency and ledger capabilities are recorded as upstream gaps rather than built here. Production stays blocked on SI-42 (stable release) by a validator rule, not by documentation alone.

## Verification

Local `npm run check` on Node 22: registry validation, engine lock validation, syntax build and the full test suite (37 tests, including 11 new). Negative cases cover lock drift (unknown fields, tag/commit/schema/image mismatch, false production eligibility), service/version drift, extra or inconsistent readiness fields, raw database details, oversized/streamed responses, wrong content type, redirect, timeout, connection refusal, insecure or credential-bearing base URLs, tampered/re-keyed/stale/future/malformed webhooks, header/payload mismatch, invalid UTF-8, oversized bodies and credential absence on probes.
